# Cross-Training Guide for Help Desk (Tier 1 → Tier 2)

**Audience:** help desk staff | **Format:** 60-minute walkthrough + hands-on | **Owner:** IT admin

## Agenda
1. **Systems map (10 min):** Okta is the front door; Google, Jira, Zoom, etc. hang off it. Show the architecture from Lab 01.
2. **What Tier 1 can do (15 min):** unlock accounts, reset MFA after verification, assign licences via groups, basic device checks.
3. **What must escalate (10 min):** security incidents, admin role requests, policy exceptions, anything touching production data.
4. **Hands-on (20 min):** each trainee resolves T-01, T-02 and T-04 in the lab.
5. **Documentation habits (5 min):** every resolved ticket gets cause + fix; every repeated ticket gets a KB article.

## Identity verification before resets
Verify via manager confirmation or video call; never by email alone. Log how verification was done.

## Escalation template
> **Summary:** … **Impact (who/how many):** … **What I checked:** … **Logs/screenshots:** … **Ask:** …

## Competency checklist
- [ ] Can reset MFA safely  - [ ] Can read an Okta System Log entry  - [ ] Can find a device in Intune
- [ ] Knows P1–P4 definitions  - [ ] Writes a good escalation
