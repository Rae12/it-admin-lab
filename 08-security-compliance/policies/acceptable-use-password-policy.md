# Acceptable Use & Password Policy

**Version 1.0 | Owner: IT**

- Use the company password manager for all work credentials; never store passwords in documents, chat or browsers.
- Passwords: 14+ characters, unique per service; password manager generates and stores them.
- SSO via Okta is used wherever supported. MFA must not be shared or bypassed.
- Do not install unapproved software or connect unapproved cloud services to company data.
- Report phishing and suspected compromise to IT within one hour.
- Company data stays in approved systems. No forwarding to personal email.
- AI tools: only approved tools may be used with company data; no customer data, credentials or confidential information in unapproved AI services.
