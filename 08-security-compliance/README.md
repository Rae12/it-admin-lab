# Lab 08: Security Standards, Policies & Audit Evidence

**Objective:** Write the policies an admin enforces, map them to controls, and practise answering an audit request.

## Deliverables
1. [Access Control Policy](policies/access-control-policy.md)
2. [Endpoint Security Policy](policies/endpoint-security-policy.md)
3. [Acceptable Use & Password Policy](policies/acceptable-use-password-policy.md)
4. [Control mapping](control-mapping.md): policy → technical setting → evidence
5. [Mock audit request & response](mock-audit-request.md)
6. [Break-glass procedure](break-glass.md)
7. [System documentation index](system-documentation-index.md)

## Exercise
Take the mock audit request, gather the evidence from your labs (screenshots, exports), and write the response. 📸 `08/audit-evidence-okta-mfa.png`, `08/audit-evidence-intune-compliance.png`

## Talking points
Policy vs standard vs procedure, how you prove a control operates (evidence over time, not a one-off screenshot), handling exceptions.
