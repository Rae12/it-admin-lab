# SOP: Employee Onboarding

**Owner:** IT | **Trigger:** HR new-hire ticket (≥5 business days before start) | **Review:** every 6 months

## Inputs required
Full name, start date, department, manager, role/level, device type (Mac/Windows), location.

## Steps
| # | Step | System | Done |
|---|---|---|---|
| 1 | Create JSM ticket linked to HR request | Jira | ☐ |
| 2 | Create Okta user with department and manager attributes | Okta | ☐ |
| 3 | Confirm group rules assigned role groups (see access matrix) | Okta | ☐ |
| 4 | Verify app tiles: Google, Zoom, Atlassian, password manager | Okta | ☐ |
| 5 | Order/stage device; enrol in Intune/Jamf PreStage | MDM | ☐ |
| 6 | Verify encryption, baseline and Zscaler client before shipping | MDM | ☐ |
| 7 | Send welcome email with day-1 instructions (no passwords in email) | Google | ☐ |
| 8 | Day 1: user sets up MFA with IT on video | Okta | ☐ |
| 9 | Add to password manager vaults for their role | PM | ☐ |
| 10 | Day 5 check-in; close ticket with evidence | Jira | ☐ |

## Evidence retained
Ticket, screenshot of group membership, device compliance state.
